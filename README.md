# Sukoon 🌿

A mindful journaling app designed to help users express their thoughts,
track their moods, and understand their emotional patterns.

## Features

- Daily journal entries
- Mood tracking
- Interactive mood trend charts
- Calendar-based journal navigation
- Inspirational quotes
- Responsive user interface
- Local storage for saving journal entries

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Recharts
- LocalStorage


## Getting Started

### 1. Clone the repository

git clone https://github.com/HUMAIDV/sukoon-mental-wellness-journal.git

### 2. Navigate to the project

cd sukoon-mental-wellness-journal

### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev
